# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-02-16

### Added
- Initial release of Ascent UI Library
- Core input components:
  - Input - Basic input field with variants (outlined, filled, standard)
  - TextField - Advanced input with label animation and adornments
  - Textarea - Multi-line text input
- Selection components:
  - Checkbox - Checkbox with label support
  - Radio - Radio button with label support
  - Switch - Toggle switch component
  - Select - Dropdown select with custom options
  - Slider - Range slider with value display
- Display components:
  - Text/Label - Typography component with multiple variants
  - Image - Image component with variants and loading states
- Action components:
  - Button - Button with ripple effect and multiple variants
  - ButtonGroup - Group of buttons with seamless styling
- Material UI inspired design
- Full TypeScript support
- Tailwind CSS integration
- Comprehensive documentation
- Example implementations
- Accessibility features

### Features
- Multiple color schemes (primary, secondary, error, success, warning)
- Multiple variants for each component
- Responsive design
- Ripple effects on interactive elements
- Loading states
- Error states with helper text
- Disabled states
- Full width support
- Icon support (start/end adornments)
- Customizable through Tailwind CSS

### Documentation
- Comprehensive README with all component documentation
- Quick Start Guide for easy onboarding
- TypeScript type definitions
- Example implementation file
- MIT License
